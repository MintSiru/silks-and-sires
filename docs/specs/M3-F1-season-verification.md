# M3-F1 시즌 자동 진행 검증 (1시즌·5시즌)

담당: haiku-tester · 선행: M3 A~E 승인, M3-A4c(G1 104) 승인 · 근거: docs/m3-plan.md F1

## 목적
실제 캘린더로 시즌을 자동 진행해 재현성·성능·출주 두수·인기마 승률·OR 분포·상금·시리즈·시상이 기획 범위 안인지 재고, 리포트로 남긴다. **엔진은 고치지 않는다** — 이탈은 리포트에 적고 Opus 가 판단한다.

## 진행 방법
- `bootstrapGame({ seed, playerName })` 후 `advanceWeek` 반복(src/engine/state, season/system 의 기존 진행 함수 — 먼저 tests/engine/seasonSystem.test.ts·tests/ui/standingsView.test.ts 가 시즌을 어떻게 돌리는지 읽고 같은 방식을 쓴다). 플레이어는 아무것도 하지 않는다(AI 만).
- 기본 모드: 시드 20261011, 1시즌(연도 전환 1주 포함 53주). FULL 모드(`VERIFY=1`): 시드 3개(20261011, 7, 424242) × 5시즌.

## 생성할 파일
1. `tests/verify/season.test.ts` — tests/verify/balance.test.ts 와 같은 구조(FULL 플래그, say() 로 지표 출력, FULL 일 때 리포트 작성). 기본 모드 제한 시간 600_000, FULL 7_200_000.
2. FULL 실행 결과 리포트 `docs/reports/2026-10-12-m3-season.md` — 맨 위에 "기준 이탈" 목록, 그 아래 지표 표.

## 지표와 기준 (기준은 리포트 판정용. 기본 모드 단언은 괄호 안 느슨한 범위만)
1. 재현성: 같은 시드 1시즌 두 번 → serializeGame 결과 문자열 같음(단언). 26주에서 저장→불러오기 후 계속 진행한 결과도 같음(단언).
2. 성능: bootstrapGame ms, 주당 진행 ms(중앙값·최대), 1시즌 총 ms. 기준: 주당 중앙값 ≤ 400ms, 1시즌 ≤ 30s(단언 안 함, 리포트만).
3. 출주 두수: 등급별(G1·G2·G3·L·핸디캡·메이든·기타) 평균·최소, 5두 미만 레이스 비율, 나라별 G1 평균 두수, g1_extra.json 24개 레이스 각각의 두수. 기준: G1 평균 ≥ 8, 5두 미만 레이스 ≤ 5%. (단언: 전체 평균 ≥ 5)
4. 인기 1위 승률(전체·G1): 기준 25~35%. (단언: 10~60%)
5. 동착(dead heat) 비율: 1착 동착 레이스 / 전체. 현재 약 4.5% 로 알려져 있다 — 측정값 기록, 기준 ≤ 1.5%.
6. OR: 시즌 종료 시 OR 상위 10두와 연령, 그해 최고 OR, 135 이상 두수, 연령별 OR 분위수(25·50·75·95%). 5시즌 FULL 에서는 시즌별 4세 이상 평균 OR 추이(드리프트). 기준: 그해 최고 124~132, 135 이상 드묾(시즌당 0~1두), 4세 이상 평균 OR 시즌 간 변화 ±3 이내.
7. 연령 분포: 시즌 종료 시 in_training 말의 연령별 두수, 7세 이상 비율(기준 ≤ 8%), 시즌 중 은퇴 두수.
8. 상금: 마주 상금 상위 10(이름·국적·tier), AE 마주 상금 합계 비율, 플레이어 상금.
9. 시리즈: 15개 시리즈별 달성마 수(5시즌 합계·시즌당), 포인트형 1위 점수.
10. 시상: 연도 전환 후 awardsHistory 의 Laurel 8부문 수상마 유무, 최우수 레이스 이름. (단언: 1시즌 후 awardsHistory 1건 이상)
11. 이름: 시즌 종료 시 모든 말 이름 정규화 중복 수(기준 0, 단언 0).

## 수용 기준
1. 기본 모드 `npx vitest run tests/verify/season.test.ts` 통과(단언 항목).
2. `VERIFY=1 npx vitest run tests/verify/season.test.ts` 를 실행해 리포트를 만든다. 시간이 오래 걸리면 백그라운드로 돌리고 끝까지 기다린다. 2시간을 넘으면 시드 1개 × 5시즌으로 줄이고 리포트에 적는다.
3. 리포트에 위 11개 지표가 모두 있고, 기준 이탈이 맨 위에 정리돼 있다.
4. `npm run typecheck && npm run lint` 통과.
