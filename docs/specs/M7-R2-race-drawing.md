# M7-R2 레이스 그리기: 게이트·주로·펄롱 표지·내 말 강조·패널

공통: docs/specs/M7-common.md. 선행: M7-R1(viewModel 에 gate·poles·playerTags·myStanding·surface 추가) 병합 뒤.
원칙 2 유지: 2D Canvas 측면 띠 한 줄, 좌측 미니맵+코스 정보, 중앙 번호 원판(승부복 주색), 우측 상위 3두+착차+분수 오즈. 3D·실사·실제 로고 금지. 간단하고 명료하게.
근거: 사용자 요청(게이트 2~3초 대기 후 출발, 옹기종기·번쩍번쩍 해소, '레이스 그래픽이랑 화면도 좀 개선'), 플레이 테스트 캡처(빈 배경, 펄롱 표지 없음, 내 말 구분 어려움, 마장 'STANDARD' 영어, 조작 버튼이 회색 상자).

## 내용
1. 게이트: gate.phase 'loading'·'ready' 동안 출발 지점에 칸막이 게이트(칸 N개, 회색 틀 + 칸 번호 작게), 원판이 칸에 들어간 모습. 'ready' 에 '출발 준비' 작은 글자. 'open' 순간 게이트 앞문이 열리는 표시(앞 테두리 사라짐 + 0.35s 밝은 선) 후 게이트는 뒤에 남아 카메라 밖으로 멀어진다.
2. 주로: 띠 바탕을 주로 색으로 — 잔디 짙은 녹색 계열, 올웨더 회갈색, 더트 갈색(캔버스 상수, 대비 4.5:1 이상 글자색 유지). 아래 내측 레일 흰 선, 위 외측 레일 옅은 선. 은은한 잔디 줄무늬(2색 띠, 카메라와 함께 흐름)로 속도감.
3. 펄롱 표지: poles 의 x 에 세로 표지 + 라벨('5f'…), 결승선은 체크 무늬 기둥 + 'F'. 지금 시작 지점 '10f' 점선은 이것으로 대체.
4. 원판: R1 의 그리기 순서 그대로, 그림자 1px 로 겹침 구분. 내 말: 두꺼운 강조 링(토큰과 비슷한 밝은 금색) + 위쪽 이름표(작은 둥근 상자, 말 이름). 다른 말 이름은 표시하지 않음(가독성).
5. 우측 패널: 상위 3두(지금 그대로) 아래 구분선 + '내 말 N위 · 선두와 X' 한 줄(myStanding, 3위 안이면 강조만). 남는 공간에 진행 막대(결승까지 비율).
6. 좌측 패널: 마장 이름 한국어(기존 going 한국어 표기 함수 재사용 — 'STANDARD' → '표준'), 주로 종류 '올웨더/잔디/더트' 한국어.
7. 조작 줄: 일시정지·1×·2×·4×·결과만·처음부터를 앱 .btn 스타일 버튼으로(현재 배속 강조, aria-pressed). 해설 문장은 캔버스 아래 한 줄 그대로.
8. 다시보기 목록: 항목을 버튼처럼 보이게(.btn 계열), 위에 '내 말 출주만' 체크(기본 켬 — 내 말 레이스가 하나도 없으면 끔).
9. 성능: 한 프레임 그리기 4ms 이내(1200×240, 20두) — 테스트나 측정 수치 보고.

## 수용 기준
- 게이트 단계별로 그리기 함수가 칸을 그린다(캔버스 목 객체로 호출 기록 테스트 — 기존 렌더러 테스트 방식을 따른다).
- 잔디/올웨더/더트 바탕색이 다르다(테스트), 펄롱 라벨이 그려진다(테스트), 내 말 이름표가 그려진다(테스트).
- 마장 '표준' 등 한국어(테스트).
