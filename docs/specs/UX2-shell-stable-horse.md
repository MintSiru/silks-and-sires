# UX2 화면 뼈대 재구성: 상단 바·메뉴·홈 · 마구간 · 말 상세

담당: Codex(gpt-6.1-sol, high — 기능 단위, 파일 많음 허용) · 설계: docs/ux-plan.md · 선행: UX1(출주 계획 API — useGame 의 racePlan·proposeRacePlan·approvePlan·removePlan·upcomingRaces)

목적: 사용자 피드백("UI/UX 가 너무 구려 정상 진행이 안 된다", 2026-10-16)에 따라 화면 구조를 다시 짠다. 가독성 우선, 한 화면에 한 가지 일, 같은 버튼은 한 곳에만.

## 구조 (docs/ux-plan.md '결정' 그대로)
1. **상단 바(공통, App 에 한 번)**: 날짜 · 승부복 아이콘 · 마주 이름 · 자금(경제 경고 색) · 진행 버튼(1주 / 다음 내 출주까지 / 4주) · '이번 주 할 일 N' 배지(누르면 홈) · 메뉴(저장 · 불러오기 · 새 게임 · 설정: 부담중량 단위, 출주 계획 자동 승인). 지금 탭마다 있는 진행·저장·자금 표시는 모두 지운다.
2. **왼쪽 세로 메뉴(좁은 화면에서는 위 가로 탭)**: 홈 · 마구간 · 번식 · 경주 · 세일 · 목장 · 경영. 레이스 데모는 메뉴에서 빼고 `?demo` 주소에서만.
3. **홈**(신규 `src/ui/home/HomeScreen.tsx` + 순수 `homeView.ts`): '이번 주 할 일' 목록(검토할 출주 계획 제안, 이름 짓기 필요, 연말 정산, 마감 임박 세일 입찰, 부상 진단·치료 결정 등 — 각 항목 누르면 해당 화면/말 상세), 이번 주 내 출주, 최근 결과 3건, 최근 이벤트 5건.
4. **마구간**(신규 `src/ui/stable/StableScreen.tsx` + `stableView.ts`): 하위 탭 현역마 / 육성마(망아지·이유마·1세) / 번식 암말 / 종마. 각 탭은 한 줄 표(이름 · 나이·성별 · 상태 칩 · 조교사 · OR · 다음 계획 또는 임신·교배 상태 · 경고 아이콘). 이름 검색 한 칸. 행을 누르면 말 상세.
5. **말 상세**(신규 `src/ui/horse/HorseDetail.tsx`, 오른쪽 넓은 패널 또는 화면 전환 — 어디서든 `openHorse(horseId)` 로 연다): 머리(이름 또는 무명 표기 · 승부복 · 나이·성별·털색 · 상태 · 조교사 · OR · 자금 관련 버튼은 넣지 않음) + 탭:
   - 개요: 능력 등급 칩 + 한 줄 해설(기존 HorseCard 해설 재사용), 컨디션·피로, 부상·치료(기존 SeasonScreen 부상 패널 이동), 거리·마장 적성 힌트, 이름 짓기(미등록이면 — 기존 HorseNamingPanel), 조교사 바꾸기.
   - 출주 계획: UX1 의 계획 목록(날짜 · 레이스 또는 조건 · 조교사 메모 · 상태 칩) + 승인 / 빼기 / 다시 짜기, 앞으로 12주 레이스에서 골라 추가.
   - 전적: 출주 표(날짜·경마장·레이스·등급·거리·마장·착순/두수·착차·기수·부담중량·OR 전후·상금). 결과 다시보기 연결.
   - 혈통: 5대 혈통표(기존 PedigreeView) + 외조부·니크·근친 요약 한 줄.
   - 기록: 이 말의 이벤트(eventLog 에서 horseId 로).
   번식 암말·종마·육성마는 탭 구성이 다르다(번식 암말: 개요·임신/교배·산자 목록·혈통·기록, 종마: 개요·북·자마 성적·혈통·기록, 육성마: 개요·혈통·기록).
6. **번식**: 지금 BreedingScreen 에서 현역마·새 게임 폼·진행 버튼·내 말 전체 목록을 빼고 '배합(번식 암말 고르기 → 종마 찾기 → 미리보기 → 예약)'과 '내 종마 사업'만. 새 게임 폼은 게임이 없을 때 전체 화면 시작 화면(`src/ui/newGame/NewGameScreen.tsx`)으로.
7. **경주**: 지금 SeasonScreen(개최·결과·다시보기·베팅) + StandingsScreen(시리즈·리딩·시상)을 하위 탭 '캘린더 / 결과 / 순위·시상'으로. 캘린더는 UX1 upcomingRaces 12주.
8. **경영**: EconomyScreen + StaffScreen 을 하위 탭 '자금 / 인맥'.
9. 세일 · 목장: 내용 유지, 진행 버튼·자금 중복만 제거. 승부복 바꾸기는 설정 메뉴로.
10. 스타일(`app.css`): 본문 15px, 표 줄 간격 넉넉하게, 상태 색 3가지(좋음/주의/위험) 토큰, 카드 그림자 대신 경계선, 버튼 위계(주 버튼 1개/화면). 다크 기본 유지.
11. 기존 화면 테스트(tests/ui)는 바뀐 구조에 맞게 고친다. 순수 함수(homeView·stableView·horseDetailView)는 새 테스트.

## 수용 기준
1. 게임이 없으면 시작 화면만, 있으면 상단 바 + 메뉴 + 화면. 진행·저장·자금 버튼/표시는 상단 바 한 곳에만 있다(코드 검색으로 확인).
2. 마구간 4개 하위 탭이 소유 말을 상태별로 정확히 나눈다(순수 함수 테스트: 현역·휴양 → 현역마, foal/weanling/yearling → 육성마, broodmare → 번식 암말, stud → 종마).
3. 어디서든 말 이름을 누르면 말 상세가 열리고, 현역마는 출주 계획 탭에서 UX1 API 로 승인·빼기·다시 짜기가 동작한다(훅 테스트 또는 렌더 테스트).
4. 홈 '이번 주 할 일'이 출주 계획 제안·이름 짓기·연말 정산·세일 마감을 모은다(순수 함수 테스트).
5. 번식 화면에 현역마가 나오지 않는다.
6. `npm test && npm run typecheck && npm run lint && npm run build` 통과. 엔진 변경 없음(필요하면 [질문]).

## 금지
엔진(src/engine) 수정 금지(UX1 API 사용만). 새 의존성 금지(라우터·UI 라이브러리 금지 — 상태로 화면 전환). 실명 문구 금지. git commit 금지.
