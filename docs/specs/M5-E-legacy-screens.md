# M5-E 화면: 기록 메뉴 · 연말 시상식 창 · 라이벌 카드 · 확립 계통 표시

담당: Codex(gpt-6.1-sol, high — UI 기능 단위) · 설계: docs/m5-plan.md, docs/ux-plan.md 가독성 원칙(화면 스크롤 최소화 — 1440×900 첫 화면 세로 스크롤 없음) · 선행: M5-B·C·D

목적: M5 엔진(연대기·왕조 목표·부계·모계·라이벌·시상식 보상)을 플레이어가 보고 즐길 수 있게 한다.

## 사용할 API (엔진 수정 금지)
- useGame: `chronicle()`, `dynastyGoals()`, `rivals()`(M5-D), 상태 `state.legacy`(lines·families), `state.awardsHistory`
- legacy/lines.ts: `establishedLineOf`, `lineLabel`, `familyOf`
- text.ts: `chronicleKo`(M5-B), eventKo(라이벌·부계 이벤트, ownerNameOf 인자)

## 범위
1. 왼쪽 메뉴에 **'기록'** 추가(홈 · 마구간 · 번식 · 경주 · 세일 · 목장 · 경영 · 기록). 하위 탭:
   - 연대기: 연도별 접이식 타임라인(최근 연도 펼침), 필터(내 기록 / 세계 / 전체), 항목 누르면 말 상세. 표 안 스크롤(높이 고정).
   - 왕조 목표: 12개 목표 카드(달성 연도 또는 진행 막대 — 진행값/목표치).
   - 부계·모계: 확립 부계 목록(시조 · 원래 계통에서 분지 · 확립 연도 · 아들 종마 수 · 그룹 우승마 수 · 내 생산 표시), 명문 모계 목록. 비어 있으면 조건 안내 한 줄(config 값 읽기).
   - 명예의 전당: 내 소유·생산마 중 G1 우승마·Laurel 수상마 목록(연대기에서 추림).
   - 라이벌: 활성·지난 라이벌(마주 이름 · 승부복 · 이유 · 맞대결 전적 · 경쟁심 막대).
2. **연말 시상식 창**: 새해 첫 주 진행 뒤 이벤트 awards_announced 가 있으면 한 번 뜨는 창 — 올해의 Laurel 수상마(부문별, 내 말 강조), 유럽 리딩 마주·생산자·종마 상위 3, 내 수상·명성 보상 합계, 올해 내 연대기 하이라이트 3줄. 닫으면 끝(다시 보기는 경주 › 순위·시상).
3. **홈 라이벌 카드**: 활성 라이벌 1~2명 한 줄씩(맞대결 전적, 최근 맞대결). 홈 첫 화면 스크롤 없음 유지.
4. **말 상세**: 혈통 탭에 확립 계통·명문 모계 표시(배지), 기록 탭에 그 말의 연대기 항목.
5. 순수 뷰 함수(`src/ui/legacy/legacyView.ts` 등)와 테스트 `tests/ui/legacyView.test.ts`. 스모크(tests/ui/ux2-shell.smoke.mjs)에 '기록' 메뉴 추가(1440×900 스크롤 없음 검사 포함).

## 수용 기준
1. 뷰 함수 테스트: 연대기 연도 묶음·필터, 목표 카드 값, 부계·모계 목록, 명예의 전당 추림, 라이벌 전적, 시상식 창 데이터.
2. 스모크: 8개 메뉴 1440×900 세로 스크롤 없음, 390px 가로 넘침 없음, 콘솔 오류 없음(브라우저가 샌드박스에서 막히면 [질문]에 적고 Opus 가 실행).
3. `npm test && npm run typecheck && npm run lint && npm run build` 통과. 엔진 변경 없음.
