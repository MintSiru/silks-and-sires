# M4-G2 30년 경제·세계 안정화

담당: Codex(gpt-6.1-sol, high — 기능 단위·장기 시뮬레이션 분석) · 근거: docs/reports/M4-G1-30year.md(G1 측정 — 판정 1·3·4·5 실패), M4 완료 기준(30년 자동 진행 시 자금 인플레 없음)

목적: G1 에서 드러난 30년 발산을 고친다. AI 마주 자금이 해마다 줄어 2054년 중앙값이 음수가 되고, 세일 낙찰률이 무너지며, 은퇴마 기록이 쌓여 저장 크기가 43.6MB, 주당 진행이 239ms → 2,261ms 로 느려졌다.

## G1 발견(재현 방법은 리포트 4장·[발견한 문제])
- A. 세일 대금 누수: 상업 생산자 로트 대금은 sales/auction.ts settleMoney 에서 breeder.funds 로 간다. AI 마주는 2026년 세일 구매 −100.8M€, 판매 수입 +0.74M€. 생산자 자금은 측정되지 않았다(무한 누적 가능성).
- B. 은퇴마 누적: world/populationSystem.ts retireHorse 가 ownerId 를 유지해 FARM_UPKEEP.retired(주당 40€)가 영구 부과. 2055년 은퇴 기록 14,817두, AI 목장 유지비 연 −34.7M€.
- C. 관계 값이 무입력 플레이에서 0개가 됨(감쇠로 지워지는 것인지 확인만).
- D. tests/verify/season.test.ts 의 STATIC_GAME 에 sales 가 없어 M3 시즌 검증이 세일 없이 돌았다.
- F. 성능: 말 기록 1.8배인데 주당 시간은 9.5배 — 기록 수 말고도 커지는 것이 있다(레이스 결과·이벤트·sireStats·OR 이력·세일 기록 등 추정).

## 범위
1. **돈의 순환(A)**: 먼저 30년 동안 AI 마주·상업 생산자·플레이어 사이 돈의 출처·행선지를 연 단위로 측정한다(장부 aiTotals·생산자 자금). 그다음 닫힌 순환 또는 안정적 평형이 되게 고친다. 권장안(다르게 하려면 이유 보고): (a) 상업 생산자 자금은 운영비·생산비로 쓰고 남는 이익의 일부를 AI 마주의 '외부 자금 유입'으로 돌리거나, (b) AI 마주·생산자 자금을 등급(tier)별 목표값 쪽으로 해마다 일정 비율 되돌리는 평균 회귀(부자 마주의 외부 자산 유입·인출 추상화). 상수는 config 에 근거 주석과 함께. 공용 rng 소비 순서 변경 금지(필요하면 독립 스트림).
2. **은퇴마(B)**: AI 소유 말이 은퇴하면 마주 소유에서 빠지게(유지비 없음 — '은퇴 목장으로 보냄' 추상화) 한다. 플레이어 은퇴마는 지금 규칙 유지. 오래된 기록 정리: 은퇴·사망 뒤 config 연수(예: 3년)가 지난 AI 말 중 **참조되지 않는** 기록은 지운다 — 참조 = 살아 있는 말의 5대 혈통 안(부·모), 종마·번식 암말 기록, 플레이어 소유·생산, sireStats 키, awardsHistory·chronicle·legacy·rivals·raceResults(보존 기간 안)·세일 기록·eventLog. 혈통표·자마 성적·종마 기록이 깨지지 않아야 한다.
3. **성능(F)**: 30년 진행을 프로파일링해 해가 갈수록 커지는 상태·계산을 찾아 줄인다(보존 정책·색인·증분 계산). 목표: 30년차 주당 중앙값 ≤ 1년차의 2배, 30년차 저장 크기 ≤ 10년차 × 1.5.
4. **D**: season.test.ts STATIC_GAME 에 sales 를 넣고 시즌 검증 수치를 다시 확인(기준 이탈 시 보고).
5. **C**: 관계 값이 사라지는 이유 확인만(의도된 감쇠면 그대로, 버그면 고침).
6. 검증: `G1_OUT=<파일> npx vitest run tests/verify/g1ThirtyYears.test.ts`(30년, 약 30분 — 백그라운드로 돌리고 결과 파일을 기다린다)를 고친 뒤 다시 돌려 docs/reports/M4-G1-30year.json·.md 를 갱신하고, 판정 표에 이전 값과 나란히 적는다.

## 수용 기준 (30년 G1 재측정)
1. AI 자금 중앙값 30년차/5년차 0.67~1.5, 1세 세일 평균가(3년 이동 평균) 30년차/5년차 0.67~1.5, 상업 생산자 자금 중앙값도 같은 범위(측정 추가).
2. 세일 낙찰률 해마다 30%~95%.
3. 인기 1위 승률: 30년 평균 25~35%, 어느 해도 38% 이하.
4. 말 기록 수·저장 크기 30년차/10년차 ≤ 1.5, 30년차 주당 진행 중앙값 ≤ 1년차 × 2.
5. 예외·NaN·음수 두수 없음. 같은 시드 결정성 유지(2년 진행 2회 동일).
6. `npm test && npm run typecheck && npm run lint && npm run build` 통과. 바뀐 고정 해시 테스트는 이유 보고 후 값만 갱신.
