# M8-R5 레이스 당일 재생 화면 다듬기

공통: docs/specs/M7-common.md. 근거: 플레이 테스트 2회차 남은 것 4 — 재생 대화상자 아래 빈 공간이 크고, 해설 문장이 장면보다 늦게 바뀐다(8f 남았는데 '깃발이 내려가고 출발합니다').

## 허용 파일
src/ui/raceDay/RaceDayReplay.tsx, src/ui/raceDay/raceDay.css, src/ui/race-viewer/RaceViewer.tsx(해설 줄 계산 부분만), src/ui/race-viewer/viewModel.ts(해설 관련 함수만, 필요하면), 관련 tests/ui

## 내용
1. 재생 단계 대화상자는 내용 높이에 맞추고 세로 가운데 정렬(빈 공간 없음). 재생 아래에 이 레이스 요약 한 줄(출주표의 내 말·작전·예상 오즈)을 둔다.
2. 해설: 지금 해설이 어떤 시각 기준으로 바뀌는지 코드로 확인해 원인을 보고하고, 장면과 맞게(게이트 대기 구간 τ<0 에는 '출발 준비' 계열, τ≥0 부터 기존 해설 시각에 게이트 대기 시간을 반영) 고친다. R1 에서 재생 시간이 게이트 대기 2.5초만큼 앞당겨진 것과 관련 있을 수 있다.
3. 다시보기 패널(경주 화면)의 같은 해설도 함께 맞는지 확인.

## 수용 기준
- 해설 시각 계산 단위 테스트: τ=−1 '출발 준비' 계열, 출발 뒤 10초 시점에 출발 해설이 아닌 다음 해설(테스트).
- 1440×900 재생 단계 캡처에서 대화상자 높이가 내용에 맞음(캡처 scratchpad/r5/).
- 스모크 PASS. 전체 npm test 금지.
