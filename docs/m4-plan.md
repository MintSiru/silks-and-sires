# M4 경제 — 개발 계획

작성: Opus · 2026-10-12 · 상태: 사용자 승인(M4 진행), 방향 결정 4건 반영
관련: docs/plan.md 5-4·8장, docs/stamina-and-nh.md(은퇴 진로·NH 시장), docs/m4-ideas.md(사용자 아이디어 10건)

## 사용자 결정 (2026-10-12)
1. **경제 모드 두 가지(새 게임 때 선택):** 캐주얼 — 파산 없음(적자는 빚으로 쌓이고 일부 기능 제한). 레거시 — 자금이 일정 기간 마이너스면 파산·게임 오버.
2. **경매:** 관심 출품마에 최대 입찰가를 걸어 두면 자동 입찰(프록시), 원하는 로트만 실시간 호가 화면으로 직접 참여.
3. **관계:** 사람별 개별 관계값(거래·위탁·그 사람 말로 우승 등으로 오르고, 시간이 지나면 조금씩 줄어듦) + 플레이어 전체 명성(그룹 우승·리딩 순위로 오름).
4. **종마 소유:** 은퇴한 내 수말을 내 목장 종마사에서 직접 계류(종부료 수입·AI 암말 교배·유지비)하거나, 국내 스터드·해외에 판매(교배권 일부 보유 옵션) 둘 다 가능.

## 목표
돈이 들어오고 나가는 구조를 완성한다: 상금·세일 판매·종부료가 들어오고, 조교료·목장 유지비·세일 수수료·종부료가 나간다. 말을 사고팔고, 은퇴한 수말이 종마가 되어 경제의 중심이 된다(유럽 경제의 핵심 = 종마 전환).

**완료 기준(기획서 8장):** 30년 자동 진행 시 자금 인플레 없음(AI 마주 자금 중앙값·플레이어 기본 전략 자금이 발산하지 않음) · 컵 프로필 종마의 70% 이상이 NH·겸용 진로 · 30년 진행 시간과 저장 크기가 한도 안 · 브라우저에서 세일 구매 → 육성 → 은퇴 → 종마 계류 → 종부료 수입 흐름 확인.
