# M6-B4 자동 조교·판매 개선 측정 (2026-10-17)

명세: docs/specs/M6-B4-smart-automation.md. 구현 haiku-coder(기준 등급·현역 상한·2세 판매 제안), 최소 현역 규칙·설정 안내 연결은 Opus.

## 확정 규칙
- 2세 자동 조교: 플레이어용 종합 등급 `AUTO_TRAINING_MIN_GRADE = 'B'` 이상만, 등급 높은 순. 현역(조교 중+휴양 중) 6두(빚이면 4두)에서 멈춤.
- 최소 현역 `AUTO_TRAINING_MIN_RACERS = 1`: 현역이 1두 미만이면 기준 미달 2세도 등급 높은 순으로 1두 보낸다.
- 나머지 기준 미달 2세는 판매 담당이 브리즈업 세일 판매 제안(빼지 않으면 위탁). 현역마 세일은 3세 이상만 받으므로 브리즈업을 놓친 2세는 남는다.
- 설정 '2세 자동 조교 보내기' 아래 안내 한 줄(settingsView.autoTrainingGuide).
