# UX 재구성 계획 (사용자 피드백 2026-10-16)

## 피드백 요지
- 조교사가 레이스 캘린더(출주 계획)를 자동으로 짜고 플레이어가 검토할 수 있어야 한다.
- 전체 UI 가 마음에 들지 않는다. 가독성이 좋고, 너무 복잡하지 않아야 한다.
- 종마·번식 암말과 현역마를 분리한다.
- 소유한 말을 누르면 정보·전적·혈통 등을 볼 수 있어야 하고, 그 창에서 출주 계획을 정할 수 있어야 한다.
- "지금 상태로는 정상적인 게임 진행이 안 된다" — Opus 가 직접 플레이해 보고 결정한다.

## Opus 플레이테스트 (2026-10-16, 헤드리스 브라우저, 보통·오너브리더)
1. 시작 직후 '시즌' 탭: 이번 주·다음 주 개최만 보이고 내 3세 현역마는 셋 다 '낼 수 있는 말 없음'. 첫 출주 가능 레이스는 5주 뒤(2월 1주)에야 나타났다. 앞으로 어떤 레이스가 있는지 볼 방법이 없어 계획을 세울 수 없다.
2. 말 카드는 눌러도 아무 일이 없다. 전적·혈통·병력은 다른 탭(번식·배합)의 카드나 표에 흩어져 있다.
3. '번식·배합' 탭에 번식 암말과 현역마가 한 목록에 섞여 있고, 종마 211두 표·배합 미리보기·내 종마가 한 화면에 길게 이어진다.
4. 진행 버튼(1주·4주·…)·저장·새 게임이 탭마다 다른 묶음으로 반복된다. 자금 표시도 두 번.
5. 탭 이름(번식·배합 / 목장 / 경제 / 인맥 / 순위·시상 / 레이스 데모)이 기능 단위라 "지금 무엇을 해야 하는지"가 안 보인다.

## 결정 (Opus — 사용자 위임)
### 화면 구조
- **상단 바(모든 화면 공통, 한 번만)**: 날짜 · 자금 · 진행 버튼(1주 / 다음 출주까지 / 4주) · 알림(이번 주 할 일 개수) · 메뉴(저장·불러오기·새 게임·설정).
- **메뉴(왼쪽 세로, 7개)**: 홈 · 마구간 · 번식 · 경주 · 세일 · 목장 · 경영. (레이스 데모는 개발용으로 숨김)
  - 홈: 이번 주 할 일(출주 계획 검토, 이름 짓기, 연말 정산, 세일 마감 등), 이번 주 내 출주, 최근 결과 3건, 중요 알림.
  - 마구간: 하위 탭 **현역마 / 육성마(망아지·1세) / 번식 암말 / 종마**. 각 탭은 한 줄짜리 간결한 표(이름 · 나이·성별 · 상태 · 조교사 · OR · 다음 계획). 행을 누르면 말 상세.
  - 번식: 배합(암말 고르기 → 종마 찾기 → 미리보기), 교배 예약·북, 내 종마 사업(판매·임대). 현역마는 나오지 않는다.
  - 경주: 레이스 캘린더(앞으로 12주 고정 일정 + 개최 예정), 결과·다시보기, 순위·시상.
  - 세일 / 목장: 지금 화면 정리(내용 유지).
  - 경영: 경제(장부·연간 요약) + 인맥(전속·관계).
- **말 상세(마구간·어디서든 말 이름을 누르면 열림, 오른쪽 넓은 패널)**: 머리(이름·승부복·나이·성별·상태·조교사·OR) + 탭 **개요 / 출주 계획 / 전적 / 혈통 / 기록**.
  - 개요: 능력 힌트(등급 칩 + 한 줄 해설), 컨디션·피로, 부상·치료, 거리·마장 적성 힌트.
  - 출주 계획: 조교사 제안 목록(날짜 · 레이스 또는 조건 · 메모 · 상태) — 승인 / 빼기 / 다른 레이스로 바꾸기 / 조교사에게 다시 짜기. '제안 자동 승인' 설정.
  - 전적: 출주 표(날짜·경마장·레이스·거리·마장·착순·착차·기수·OR 변화·상금).
  - 혈통: 5대 혈통표(외조부·니크·근친 표시).
  - 기록: 이 말의 이벤트(부상·OR 변동·이름 등록·판매 등).
### 가독성 원칙
- 한 화면에 한 가지 일. 긴 표는 접고 검색·필터를 위에 둔다.
- 숫자보다 등급·한 줄 해설을 먼저, 세부 숫자는 펼치기로.
- 같은 정보·버튼은 한 곳에만.
- 상태 색은 3가지(좋음·주의·위험)만.
