# M4 경제 — 사용자 아이디어 (2026-10-12)

M4 계획(docs/m4-plan.md, 아직 없음)을 쓸 때 기획서 5-4장·8장(M4 완료 기준)과 함께 반영한다.

## 사용자 제안
1. **내부거래(프라이빗 세일):** 관계가 좋은 오너브리더의 유망주를 경매 없이 개인 거래로 산다.
2. **미국 서러브레드 경매:** 미국 대형 1세마 경매(9월, 여러 날·여러 '북' 단계) 모티브. 세일 회사·장소 이름은 가상(원칙 1 — 실제 세일 회사명 금지).
3. **조교사 세일 동행:** 전속 조교사 또는 관계가 좋은 조교사와 세일에 간다. 조교사의 '상마안'(말 보는 눈) 능력에 따라 출품마 코멘트의 정확도가 달라진다.
4. **종마 판매:** 은퇴한 내 수말을 주요국(영·아·프·독·이) 스터드에 팔거나, 해외(미국·일본·호주 등)에 판다. 해외 판매는 은퇴 처리(게임 세계에서 빠짐).

## 구현 시 필요한 것 (Opus 메모)
- 관계도: 마주·오너브리더·조교사와 플레이어의 관계값(현재 없음). 거래·위탁·성적으로 오르내림. 1·3 의 공통 기반.
- 조교사 '상마안' 능력치(현재 Trainer 에 없음, skill 과 별개의 숨김 값). 코멘트 = 출품마 실제 능력 + 상마안에 반비례하는 오차. M3-C3 의 '조교사 소견(trainerReportKo)' 문구 체계를 재사용.
- 미국 세일 출품마: 미국 종마 자마(실명 종마 중 standsIn US). 더트 프로필 말은 유럽 잔디 적성이 낮을 수 있다는 위험이 구매 판단에 들어가야 재미있다.
- 종마 판매: 국내 스터드 판매는 그 수말이 종마 목록에 들어가 AI 생산에 쓰이고(부계 확립 M5 와 연결), 해외 판매는 세계에서 빠진다. 가격 = 성적·혈통·시장 수요.
- 기존 기획의 M4 범위: 세일 경매(이유마·1세마·브리즈업·현역마), 종부료, 종마 전환(평지·겸용·NH·거세), NH 스토어 세일 추상화, 유지비. 완료 기준: 30년 자동 진행 시 자금 인플레 없음.
- M3-F2d(AI 조기 은퇴)에서 '종마 은퇴'로 빠진 AI 수말을 M4 에서 실제 종마 목록에 넣을지 함께 결정.
