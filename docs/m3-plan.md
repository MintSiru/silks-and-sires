# M3 시즌 — 개발 계획 (초안)

작성: Opus · 2026-10-11 · 상태: 사용자 승인 대기
관련: docs/race-calendar-plan.md(경마장·캘린더), docs/naming.md(이름), docs/stamina-and-nh.md(거리 프로필·NH)

## 목표
한 시즌(4월~11월)을 처음부터 끝까지 굴린다: 캘린더대로 레이스가 열리고, AI 마주·조교사·기수가 말을 출주시키고, OR 레이팅과 핸디캡이 움직이고, 플레이어는 자기 말을 출주시켜 실황으로 보고, 시즌 끝에 3개 단체 시상과 리딩 순위가 나온다.

**완료 기준(안):** 시드 고정 1시즌 자동 진행 재현 100% · 1시즌 진행 60초 이내 · 인기 1위 승률 25~35% 유지 · G1 평균 출주 8~14두 · 브라우저에서 출주 → 실황 → 결과 → 시상 흐름 확인.

## 새 요소 설계 요약

### 말의 성격 (C5)
- 성격 축 5개(숨김, 0~100): **기세**(앞으로 나가려는 성향), **침착**(흥분·과열 억제), **투쟁심**(경합에서 버팀), **겁**(무리 속·게이트 두려움), **고집**(기수 지시 거부).
- 레이스 반영: 기세↑·침착↓ → 초반 과열(스태미나 손실)·선행 각질 유도, 겁↑ → 출발 늦음·바깥 선호, 투쟁심↑ → 접전 근성 보정, 고집↑ → 작전 지시 무시 확률.
- **각질 결정:** preferredStyle 을 성격 + 능력(순발력·스태미나)에서 파생시키고, 조교로 일부 교정 가능. → "성격에 따라 각질이 달라진다"를 구현.
- 유전: 부모 평균 + 큰 노이즈(유전력 낮게). 단서: 조교사·기수 코멘트("게이트에서 예민합니다" 등).

### 털색 (C6)
- 단순화한 유전: 밤색(chestnut, 열성) / 갈색(bay) / 흑갈색(brown) / 흑색(black) / 회색(grey, 우성, 나이 들수록 밝아짐) / 조모(roan, 드묾). 흰 반점(얼굴·다리) 선택.
- 실명 종마는 위키백과 인포박스 Colour 값을 데이터에 추가(data 티켓). 표시: 말 카드·혈통표·띠 원판 테두리 등.

### 이름 확장 (C7)
- docs/naming.md 의 출처 × 템플릿 구조 + 동사형(Enable형), 합성형(Sea The Stars형), 긴 구절형(18자 이내), 외국어(프·이·독), 마주 고유 음절형.
- **위인 이름**은 원칙 1(실존 인물 금지)과 부딪친다 → 아래 질문 Q4.
