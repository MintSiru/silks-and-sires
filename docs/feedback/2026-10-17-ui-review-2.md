# UI 3차 검토 종합 (아스트라·아르곤 재검토, 2026-10-17)

원문: 사용자 중개(대화 기록). 대상: M6-U2~U10 반영 뒤 스크린숏(01d83d7). Opus 가 두 답을 비교해 합쳤다. **★ = 두 모델 공통 지적(우선)**.

## 판정 요약
- 개선됨(두 모델 일치): A1 설정 모달, A2 토스트, A4 시즌 배지, B1·B2 홈 결과·이벤트, C1~C3 마구간, D1·D3 번식, E1 캘린더 요약, F2 세일 일정 표, G1 목장 단계, H1·H2 경영 KPI·손익, J2 출주 계획, J4 혈통, J5 말 기록, L1~L3 시작 화면.
- 부분 개선·남은 문제: A3(할 일 숫자), A5(마지막 행 잘림), D2, E2·E3, H3, I1·I2(16번 미갱신으로 확인 불가), J1, J3, K(튜토리얼 미착수 — M6-T).
- 처리 완료(Opus): H3 시설 건설비·유지비 장부 분리(f0d3bd7).
- 확인 불가로 남은 것: 확인창·공사 중 상태·판매 탭·5대 혈통·대량 연대기 → 스크린숏 자료를 늘려 다음 검토에서 확인(V8).

## 새로 생긴 문제·남은 문제 (합친 목록)
### 공통
1. ★ **마지막 행 반쪽 잘림**: 경영(손익 표·최근 장부), 말 상세 전적, 홈 최근 결과 3번째, 경주 캘린더. 첫 화면은 완전한 행 단위로 끝나야 한다(행 높이 줄이기 → 그래도 넘치면 목록 내부 스크롤 + padding-bottom).
2. 표 가로선 끊김: 번식 '근거' 행·출주 계획 '조작' 열(아르곤). 행 테두리는 tr 단위로, 근거는 셀 안 하위 블록으로.
### 홈
3. ★ 브리핑 제목 옆 '0' 과 본문 '출주 예정 1건' 이 서로 다른 기준 → 브리핑 제목 숫자 제거(결정 대기 수는 상단 '할 일' 배지에만).
4. '최근 이벤트 5건' 인데 빈 목록 → 제목 '주요 사건'(표시 한도는 보조 문구 '최근 5건까지').
5. '출주 예정' 카드에 등급 배지·거리 천 단위 쉼표(마구간 '다음 출주' 와 같은 포맷).
### 마구간
6. 탭 줄 아래 구분선이 검색창 앞에서 끊김 → 탭+검색 감싸는 헤더 전체에 하단선.
7. 빈 '확인' 열 → 표시할 내용이 없는 행만 있으면 열 숨김.
8. 조교사 글자 13px·보조색(크기만 줄여 기준선이 어긋남).
### 번식
9. ★ 행 정렬: 같은 행의 첫 줄 높이가 열마다 다름 → td vertical-align: top, '근거'는 암말 셀 안 하위 블록(가로선 일직선).
10. 종합 판단 문구: 주의가 있으면 '주의 — 근친 검토 필요' 를 먼저, 긍정 요소는 뒤(또는 근거로).
11. 상단 조작 줄 기준선(아르곤) — 높이 36px·align-items: flex-end.
### 경주 캘린더
12. ★ 주 행이 2줄이 되어 12주 중 7주만 보임 → 접힌 행은 한 줄(대표 경주 + '외 N'), 행 높이 40~44px.
13. ★ 하단 '이번 주·다음 주 개최 · 출주 신청' 이 출주 계획과 경쟁 → 제목 '이번 주·다음 주 개최', 말 이름은 출주 계획으로 연결(신청 버튼은 유지하되 보조).
14. ▸ 펼침 표시 14px·보조색, 행 호버 배경.
### 세일
15. 발표 전 세일의 버튼 이름 '카탈로그 보기' → '발표 일정 보기'(공개 뒤 '카탈로그 보기').
16. 후원 진행 막대 대비(트랙 배경·테두리), 오른쪽 카탈로그 칸이 내용보다 크게 비어 있음(아르곤).
### 목장
17. ■□□ 채운 칸 좋음 색·빈 칸 흐린 색, 14px. 여러 줄 행 vertical-align 통일. 좌우 높이 차(아스트라) — 왼쪽 열 아래 빈 공간 줄이기.
### 경영
18. ★ 주별 장부 헤더 한 줄(▸ · 날짜 · 건수 · 합계), 손익 표 셀 패딩 축소로 모든 지출 항목 표시.
### 기록
19. 연대기 링크 밑줄이 셀 끝까지 늘어남(아르곤) → 링크 width: fit-content.
20. 배지와 본문 종류 반복('첫 출주' 배지 + 'Corvane Haven, 첫 출주') → 본문은 대상·경주·결과만. '최신순' 중복 → 목적 줄에서 뺌.
### 말 상세
21. 개요: 세부 등급 5개를 가로 등급 칩 한 줄로(색 배지), 코멘트 불릿은 그 아래 2줄(아르곤).
22. ★ 전적: 행을 2줄로(날짜·착순·경주·조건·상금), 기수·중량·OR·착차·다시보기는 행 펼침(아스트라) 또는 오른쪽 작은 열 — 5전 전부 첫 화면에.
23. ★ 출주 계획: 등급 배지와 두 줄 레이스명 정렬(grid 72px + 1fr, align start). 메모 모순('거리 적성에 맞춤' + '거리 연장 도전') → 거리 판단을 하나만: 힌트 밖이면 '거리 연장 도전 — 적성 상한보다 214m 김' 만 보이고 조교사 원문은 펼침.
24. ★ 혈통: 3대 칸 높이 균일(말단 최소 28px, 이름 14/20), 상위 칸은 자손 묶음 가운데, 링크 밑줄은 호버 때만. 기록 탭 경주 항목에도 등급 배지.
### 설정
25. 판매 체크박스 아래 붙은 교배 자동 예약 설명 → 별도 '교배 예약' 항목으로 분리, 항목 간격 16px. 부담중량 라벨 옆에 드롭다운(간격 16px).
### 시작 화면
26. '추천 조건' 안내는 버튼처럼 보이지 않게 왼쪽 강조선 콜아웃, '캐주얼(고급 설정)' 표기. 오른쪽 열 아래 빈 공간(선택 규칙 요약 등) — 아르곤.
### 스크린숏 자료(검증 범위)
27. ★ 16번 연대기 예시가 옛 이미지 → capture-screens 에서 다건 기록 저장본으로 다시 찍기(접힘·'전체 N건' 펼침 2장). 판매 탭·공사 중 목장·5대 혈통·모두 승인 확인창·설정 새 게임 확인 단계도 추가.
### K(튜토리얼) — M6-T 로
28. ★ 첫 시즌 체크리스트, 용어 점선 밑줄 도움말, 'OR 95 (상위권)' 판정 병기, 진행 전 중요 결정 정지·요약.
