## F. 총평
- "UI 가 너무 불친절" — "위닝 포스트·더비 스탈리온 시스템을 UI 만 다듬어서 가져와도 잘 될 것" → 화면 전반 재설계 필요.

## 사용자 결정 (2026-10-12)
- 우선순위: **M4 먼저**, 이 피드백은 M4 뒤(또는 M4 화면 작업 때 함께)에 반영.
- D3 혈통표 빈칸: **원칙 1 유지** — 모르는 암말은 '—', 그 암말의 부(외조부)는 표시, 빈칸이 많아 보이지 않게 표 배치 압축.
- E4 예후불량: **넣되 새 게임 설정에서 끌 수 있게**(아주 드물게).
- E3 수득 상금 조건: **넣지 않음**. 대신 급이 안 맞는 레이스에 출주할 때(핸디캡에서 최고·최저 부담중량에 걸리거나, 상대가 훨씬 강해 승산이 낮을 때) **경고**를 띄운다.
