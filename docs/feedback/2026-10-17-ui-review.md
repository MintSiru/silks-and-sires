# UI 2차 검토 종합 (아스트라·아르곤, 2026-10-17)

원문: 사용자 중개(대화 기록). 스크린숏: docs/feedback/screens/. Opus 가 두 답을 비교해 합쳤다. **두 모델 공통 지적 = ★(우선)**.

## 판단 기준 (Opus)
- 원칙 유지: 한 화면 한 가지 일, 등급·한 줄 설명 먼저, 같은 정보 한 곳, 상태 색 3가지, 1440×900 첫 화면 스크롤 없음, 다크 테마.
- 새 의존성 금지 → 웹 글꼴(Pretendard 등)은 넣지 않고 시스템 글꼴 스택 유지. 호버 미리보기 카드(아르곤 4-3)는 M6 범위 밖(후속).
- 엔진 수정 없이 화면만. 단 기록 정렬 버그(I-1)는 화면 정렬 문제.

## 합친 목록
### A. 공통 셸·디자인
1. ★ 메뉴·설정을 **모달**로(본문을 밀지 않음). 그룹: 저장 관리 / 진행·자동화 / 표시·외형, 새 게임은 위험 영역+확인. 체크박스 글자 겹침 버그 수정. 자동화 설정은 명시적 단일 선택('조교사 제안 자동 신청' / '내가 승인한 계획만').
2. 진행 완료 알림은 문서 높이를 늘리지 않는 **토스트**.
3. ★ '이번 주 할 일' 중복: 상단은 배지(누르면 홈), 홈 카드는 '이번 주 브리핑(다음 진행 때 자동으로 일어날 일)'.
4. 날짜 옆 **시즌 배지**(예: '여름 경주 시즌', '교배 예약 기간').
5. ★ 디자인 토큰: 글자 위계(제목 20/28·700, 섹션 15~18·600, 본문·표 14/22, 보조 12/18), tabular-nums, 표면 색(바탕·카드·패널·구분선), 상태 색 3종(좋음·주의·위험 배지 = 배경 14%·테두리 40%·밝은 글자), **등급 배지**(G1·S 금, G2·A 청, G3·L·B 녹/동, 그 밖 회색), 착순 배지(1착 금, 2~3착 청, 그 밖 회색), 표 규칙(헤더 sticky, 날짜·상태·버튼 열 nowrap, 셀 8~10px·12px, 마지막 행 잘림 방지), 링크 스타일(밑줄 대신 옅은 하단선), 말 상세 드로어 분리감(밝은 표면+그림자+배경 흐림), 포커스 링 2px.
### B. 홈
1. ★ 결과는 **내 말 관점**('Corvane Haven 5착/11 · 경주명'), 우승마는 보조.
2. ★ 최근 이벤트에서 출주 신청·결과 중복 제거 → 부상·출산·세일 낙찰·목표 달성 같은 주요 사건만.
3. 등급·착순은 배지로.
### C. 마구간
1. ★ '다음 출주' 2줄(날짜·등급·거리 / 레이스명), 열 폭 고정, 잘림 없음.
2. ★ 종합 등급 배지·컨디션 상태 칩·**최근 5전 착순 띠**(예 5-11-2-6-2, 1~3착 강조) 열 추가, 조교사는 보조.
3. 검색은 탭 줄 오른쪽 한 칸(라벨 없음).
### D. 번식(교배 제안)
1. ★ 열 축소: 암말 / 제안 종마 / 종부료 / 종합 판단(장점·위험 요약, 근친 기준 넘으면 주의 색) / 상태·조작. 근거(거리 보완·메모)는 행 펼치기.
2. ★ '모두 승인' 전 확인창(두수·총 종부료·주의 배합), 조작 줄 높이·기준선 정렬, 비활성 사유.
3. 암말 수준은 등급 배지로.
### E. 경주 캘린더
1. ★ 주별 행 = 주차 / 주요 고정 레이스(등급 배지) / 내 말 표시만. 반복되는 일반 개최·예상 종류는 펼쳤을 때만.
2. 주차 행 펼침 표시를 분명히(▸ 크게, 행 전체 클릭), 펼치면 그 주 레이스 목록.
3. 출주 조작은 말 상세 '출주 계획'으로 연결(중복 조작 제거).
### F. 세일
1. ★ 후원 등급은 제목 옆 작은 배지+진행 막대로, 판매 제안 0두면 한 줄.
2. ★ 일정 표 열 압축(종류·월·상태를 세일 이름 아래 보조 줄로) → '로트' 잘림 해소.
3. 진입 시 가장 가까운 세일 자동 선택, 발표 전이면 발표 예정 주·거래 시점 안내.
4. 구매 / 판매(판매 제안·개인 거래·내 말 출품) 하위 탭으로 정리.
### G. 목장
1. ★ 시설별 '현재 → 다음 단계' 효과 차이, 단계 진행 막대(■□□).
2. ★ 공사 중이면 상단에 공사 상태·완료 예정 주 고정, 다른 '공사 시작'은 비활성+사유.
3. 레이아웃 좌우 높이 맞춤(목장 매물을 왼쪽 아래로).
### H. 경영
1. ★ 상단 KPI 타일(총수입·총지출·순손익 + '운영 여유/지출 주의').
2. ★ 금액 오른쪽 정렬·tabular-nums·수입 초록/지출 보조색, 비중 막대.
3. 장부는 주별 묶음(펼치면 개별), 비용 이름 정리(시설 유지비/시설 건설비/목장 기본 유지비).
### I. 기록
1. ★ 정렬 버그: 같은 해 안에서 날짜 내림차순(지금은 id 순번이라 6월 다음 9월). 기본 '최신순' 명시.
2. ★ 종류 태그 배지([G1 우승][라이벌][첫 출주]…), 단일 필터에서는 '내 기록' 배지 숨김, 연도 기본은 주요 순간 3~5건 + '전체 N건' 펼치기.
3. 탭마다 목적 한 줄('가문의 주요 순간', '이어지는 혈통과 후계마' 등), 빈 상태 안내.
### J. 말 상세
1. 개요: '종합 B — 한 줄 총평' 먼저, 세부 등급·코멘트는 보조(불릿), 적성 거리·성장형 칩, 컨디션 '최상·피로 없음' 말로(수치는 작게), 조교사 변경은 헤더 옆 '변경' → 작은 폼(폭 320px).
2. ★ 출주 계획: 상태·조작을 모드와 일치(자동: '자동 출주 예정'·[제외] / 승인제: '승인 대기'·[승인][제외]), 날짜 nowrap, 레이스 앞 등급 배지·조건은 둘째 줄, 메모에 거리 힌트 밖이면 '거리 연장 도전' 등 구체 이유(엔진 메모 문자열은 그대로 두고 화면에서 거리 힌트와 비교해 보조 문구 추가).
3. ★ 전적: 열 순서 날짜 / 착순(배지) / 경주 / 조건, 마장 한국어(원문은 툴팁), 상금 열, 상단 요약 '최근 5전 2착 2회'.
4. ★ 혈통: 기본 3대(화면 안), '5대 보기' 토글, 빈 칸 '—' 한 줄, 부측·모측 색 구분(왼쪽 선 파랑/보라), 인브리드 조상 강조.
5. ★ 기록: 단일 타임라인(최신순), 이 말 관점 문장('5착 — 경주명'), 연대기 항목은 '주요 순간' 배지로 구분, 운영 로그(신청·취소)는 접힘.
### K. 처음 하는 플레이어 (→ M6-T 튜토리얼에 반영)
1. ★ 첫 시즌 체크리스트(말 상태 확인 → 출주 계획 검토 → 진행 → 결과 확인 / 교배 제안 확인), 실제 화면으로 연결.
2. ★ 용어 도움말(OR·니크·근친·블랙타입·리스티드·펄롱·마장) — 점선 밑줄 + 한 줄 풀이, 숫자 옆 판정('OR 95 (상위권)').
3. 진행 버튼이 '중요 결정(미승인 필수 결정·큰 지출·판매 확정)' 앞에서 멈추고 무엇이 자동 실행될지 미리 요약.
### L. 시작 화면
1. ★ 기본(마주 이름·추천 조건)만 펼치고 시드·세부 규칙·승부복 레이어는 '고급 설정' 접기.
2. ★ 선택지마다 결과 중심 한 줄 설명.
3. 주 버튼 '이 조건으로 시작'을 크게(카드 하단 전체 폭 44px), 승부복은 미리보기+'꾸미기'(팔레트 하나 + 부위 탭).
