# 스테이어 종마와 내셔널 헌트(NH) 시장 설계

작성: Opus · 2026-10-11 · 관련: 기획서 5-1(혈통), 5-4(경제), 8장 M2·M4

## 1. 결론

참고한 글의 핵심 주장, 즉 "진짜 장거리마는 평지 생산에서 외면받지만, NH 종마로 수요를 유지하고 그 피는 딸을 통해 평지에 남는다"는 구조는 사실에 가깝다. 다만 실제 시장은 '스프린터 대 스테이어'로 나뉘지 않는다. **스피드(8f 이하) · 클래식 중거리(10f) · 12f 이상**의 3층 구조이며, 낙인이 찍히는 지점은 12f 이상부터다. 게임은 이 3층(+컵 레이스급) 구조를 종마 가치 계수로 구현하고, 은퇴 시 **평지 / 겸용 / NH 종마 / 거세** 선택지를 둔다.

## 3. 원 글을 게임용으로 다듬은 모델

```
                 평지 상업 가치   NH 가치   대표 진로
스피드 (~8f)        ★★★★★        ★          평지 종마
클래식 (9~10f)      ★★★★★        ★★         평지 종마 (최상위 쏠림)
중장거리 (11~12f)   ★★★          ★★★        평지 / 겸용 / 프랑스 평지
컵 레이스 (14f~)    ★            ★★★★★      NH 종마 (아들은 거세 → 장기 현역, 딸은 평지 번식 암말)
```

- **부마가 스피드, 외조부(모마의 아비)가 스태미나**를 맡는 배합이 기본형이다. 법칙이 아니라 경향이므로, 게임에서는 보너스·확률로만 반영한다.
- 스테이어의 피는 **딸 → 번식 암말 → 외조부 효과**로 평지에 남는다. 그래서 스테이어 종마는 '외조부(broodmare sire) 평가'라는 두 번째 가치 지표를 가진다.

## 4. 게임 시스템

### 4-1. 거리 프로필
모든 말은 현역 성적으로 `distanceProfile`(speed / classic / middle / cup)이 정해진다. 종마 가치와 배합 힌트가 이 값을 쓴다.

### 4-2. 은퇴 진로 선택 (수말)

| 진로 | 조건 | 수입 | 특징 |
| --- | --- | --- | --- |
| 평지 종마 | 평지 가치가 기준 이상 | 높은 종부료, 적은 두수 | 유행에 민감. 첫 세대 성적으로 크게 재평가 |
| 겸용 종마 | 중장거리·컵 프로필 | 중간 종부료 | 평지·NH 생산자 양쪽에서 신청 |
| NH 종마 | NH 가치가 기준 이상 | 낮은 종부료, 많고 안정된 두수 | 유행 영향 적음. 자마 성적은 NH 요약 결과로 갱신 |
| 거세(현역 연장) | 언제든 선택 가능, 되돌릴 수 없음 | 상금 | 기질·내구성 상승, 10세까지 현역. 번식 불가, 클래식급 레이스 출주 불가 |

AI 마주는 기대 가치가 가장 높은 진로를 고르고, 플레이어는 직접 고른다.

### 4-3. 배합 화면의 '역할 분담' 힌트
- 배합 화면에 **스피드 담당 / 스태미나 담당** 표시를 둔다. 부마는 자신의 프로필로, 모마는 자기 성적과 외조부 프로필을 합산해서 판정한다.
- 보완형(부마 스피드 + 모계 스태미나)은 잠재 능력 상한 굴림에 보너스를 준다. 이것이 더비 스탈리온식 '이론으로 설명되는 배합'이다.
- 양쪽 모두 스피드면 스프린터, 양쪽 모두 컵이면 장거리 전문가가 나올 확률이 커진다. 이는 의도된 선택지이며 실패가 아니다.

### 4-4. 시장 흐름(트렌드)
- 국가별·프로필별 수요 계수가 매년 조금씩 변한다. 초기값은 영국·아일랜드가 스피드 쪽, 프랑스는 중거리에 관대, 아일랜드·프랑스는 NH 수요가 크다.
- 이벤트: 가상의 '스테이어 보너스 시리즈'(장거리 레이스 연속 우승 보너스)가 열리면 컵 프로필 현역마 가치가 일시 상승한다.
- 독일형 종마 승인: 독일에서 종마로 서려면 레이팅·건강 기준을 넘어야 한다.

### 4-5. NH 시장 (장애 경주 확장 전 추상화 버전)
장애 경주 레이스 화면은 후속 확장으로 미룬다. 우선 경제 흐름만 구현한다.
1. NH 종마의 수컷 자마는 기본적으로 3세에 **스토어 세일**로 판매된다. 가격은 종마의 NH 평판 × 체형 × 혈통으로 정한다.
2. 플레이어는 보유를 선택할 수도 있다. 보유하면 시즌마다 'NH 성적 요약'(입상 횟수·상금)이 확률로 생성된다.
3. 모든 NH 자마의 요약 성적이 모여 종마의 **NH 평판**을 갱신하고, 이것이 다음 해 NH 종부료와 신청 두수를 정한다.

### 4-6. 장기 목표 연동
- 위닝 포스트식 '부계 확립'에 더해, 스테이어용 **'모계 명예(외조부) 확립'**을 추가한다. 조건은 내 생산 스테이어 종마의 딸들이 낳은 자마가 그룹 우승 N회를 달성하는 것이다.
- 업적 예: '한 줄만 포기하고 피를 잇다'. 내 컵 프로필 종마가 NH 종마로 서고, 그 외손이 평지 G1을 우승하면 달성.

## 5. 데이터 모델 초안 (M2·M4 명세에서 확정)

```ts
type DistanceProfile = "speed" | "classic" | "middle" | "cup";
type StudRole = "flat" | "dualPurpose" | "nh";

interface StallionCareer {
  role: StudRole;
  flatValue: number;          // 평지 시장 가치 지수
  nhValue: number;            // NH 시장 가치 지수
  nhReputation: number;       // NH 자마 요약 성적 누적
  broodmareSireRating: number; // 외조부 평가
}

interface MarketTrend {
  // 국가 × 프로필별 평지 수요 계수, 국가별 NH 수요 계수
  flatDemand: Record<CountryCode, Record<DistanceProfile, number>>;
  nhDemand: Record<CountryCode, number>;
}
```
